## Pseudocode source snippets

Use `pseudocode`, `pseudo` or `algorithm` fences. Source editing provides completion, linked snippet fields, block folding and matching. Accepted snippets insert END statements; ordinary typing does not. Inline source previews are disabled; Split/Preview and static output retain academic rendering. Built-ins are notation, never executed. See [pseudocode](pseudocode.md).

### procedure

Procedure with matching END.

```pseudocode
PROCEDURE name(parameters)
  action
END PROCEDURE
```

### function

Function with return and matching END.

```pseudocode
FUNCTION name(parameters)
  RETURN result
END FUNCTION
```

### if

Conditional block.

```pseudocode
IF condition THEN
  action
END IF
```

### ifelse

Conditional with an alternative.

```pseudocode
IF condition THEN
  action
ELSE
  alternative
END IF
```

### for

Inclusive counted loop.

```pseudocode
FOR i ← start TO finish DO
  action
END FOR
```

### foreach

Loop over a collection.

```pseudocode
FOR EACH item IN values DO
  action
END FOR
```

### while

Precondition loop.

```pseudocode
WHILE condition DO
  action
END WHILE
```

### repeat

Postcondition loop.

```pseudocode
REPEAT
  action
UNTIL condition
```

### assign

Assignment.

```pseudocode
target ← expression
```

### swap

Exchange two values.

```pseudocode
SWAP left, right
```

### quicksort

Zero-indexed Quicksort with Lomuto partition.

```pseudocode
INPUT A (array of comparable values)
OUTPUT A sorted in ascending order

PROCEDURE QUICKSORT(A, lo, hi)
  IF lo < hi THEN
    p ← PARTITION(A, lo, hi)
    QUICKSORT(A, lo, p - 1)
    QUICKSORT(A, p + 1, hi)
  END IF
END PROCEDURE

FUNCTION PARTITION(A, lo, hi)
  pivot ← A[hi]
  i ← lo - 1
  FOR j ← lo TO hi - 1 DO
    IF A[j] ≤ pivot THEN
      i ← i + 1
      SWAP A[i], A[j]
    END IF
  END FOR
  SWAP A[i + 1], A[hi]
  RETURN i + 1
END FUNCTION

QUICKSORT(A, 0, length(A) - 1)
```
