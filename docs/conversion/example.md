## A bounded error

The estimate follows from :ref[thm-bound]; see :ref[tab-error].

:::theorem[A bounded square]{#thm-bound}
For $0\le x\le1$, $x^2\le x$.
:::

:::proof[Proof]
Multiply $x\le1$ by the nonnegative value $x$.
:::

:::equation[Error]{#eq-error}

$$
e(x)=x-x^2
$$

:::

:::table[Exact error]{#tab-error}

| $x$ | $e(x)$ |
| --: | -----: |
|   0 |      0 |
| 0.5 |   0.25 |
|   1 |      0 |
:::
