# Glass showcase screenshots

The homepage, reading and Studio scenes are captured from an isolated local Glass demo at a 1440 × 960 viewport, with matching light and dark appearances. Studio uses the same generic notebook. No author credentials, private writing or analytics records appear in these images.

The reading and editor scenes use [this short sample note](note.md), compiled with the real Markdown engine. The note is documentation sample content, not an article added to the starter notebook. Homepage curation and collection labels are demo settings.

Images are metadata-free WebP files. The repository READMEs choose the matching variant with a `picture` element. The images illustrate the interface at capture time; the source commit badge in Studio identifies that build.

For a future capture, use a temporary notebook and wait for fonts, page transitions, source decorations and rendered previews to settle. Preserve normal interface styling, use generic data and review the actual pixels before replacing the files.
