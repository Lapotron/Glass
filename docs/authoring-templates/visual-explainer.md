## The structure

:::mindmap[From curiosity to understanding]

- Curiosity
  - Observe
    - Notice a pattern
    - Ask a question
  - Explain
    - Build a model
    - Test a prediction
:::
::::comparison[Complementary approaches]
:::option[Analytical]
Derive a consequence from a stated model.
:::
:::option[Experimental]
Measure a response and compare it with the model.
:::
::::

:::timeline[How the idea develops]

- **Observation** — Notice something worth explaining.
- **Model** — State a clear, testable account.
- **Experiment** — Compare prediction and evidence.
- **Revision** — Improve the account.
:::
## What to remember

Explain the main relationship in plain prose, then connect it to the next question.
